# Additional plugin-service support artifacts

`evidence/windows-optionsplus/plugin-service-native.json` records exact identities, PE/CLI classification, import DLLs, original string offsets, fixed versions where present, and bounded negative searches. This was read-only static triage, without executing the artifacts or switching the active REA target.

`LogiPluginServiceExt.exe` is a 3,740,312-byte native x86-64 Windows console executable, SHA-256 `c17a71b385b534067b21f0aff60ee85603659e89897746419313720683812d45`. It contains local-client/named-pipe connection diagnostics (`0x00241f38` onward; pipe prefix `0x00242438`), contextual-display device functions (`Feature19a1ContextualDisplay::setImage` at `0x00245ae8`), device/key/encoder event names (`0x0028b6d8..0x0028b8b8`), image/brightness/keepalive/DFU method names (`0x0028b9e0..0x0028bbd0`) and Loupedeck service/window names (`0x0028c050`, `0x0028c240`, `0x0028c2b0`, `0x0028c490`, UTF-16LE). This supports the inference that it bridges local plugin-service IPC to Loupedeck/contextual-display hardware IO. It is not static proof of a ring renderer. The exposed image methods target contextual-display device IO; a reference to display images is not sufficient to identify an on-screen Actions Ring.

`NativeApi.dll` is a 284,824-byte **managed PE/CLI assembly**, SHA-256 `35328d0e4506ef94261b3f0d6f4b9ff7f5675f818a44d0bdacaac64e26ff107c`, despite its name. Metadata strings include `SendInput` (`0x0003d513`), `SendKeyboardShortcut` (`0x0003d42e`), `SendKeyboardEvent` (`0x0003cf3c`), `OverlayBase` (`0x0003831e`), `MouseClick` (`0x00039430`), `CaptureAllScreens` (`0x0003bdcd`) and clipboard methods (`0x00036018`, `0x00036029`). These suggest an OS-integration abstraction, but method bodies and exact call relationships require the separately delegated managed analysis.

The recorded ASCII and UTF-16LE searches over both files found no exact MX4/B042/B048, radial_menu/Actions Ring, or specific 19B0/19C0/force_sensing literals. The scope is printable-string triage; these are bounded negative searches, not proof that unnamed/encoded functionality is absent. No live behavior or direct physical-device support was verified.
